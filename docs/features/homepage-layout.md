# 03. 首页核心模块布局 (Homepage Layout)

本页面的设计参照了顶流度假村（四季酒店）的视觉呈现与用户链路，结合 **“美丽度假酒店 MEILI RESORT HOTEL”** 的品牌基调与需求，划分为以下主要展示区/流向：

## 1. 顶部视频区 (Video Hero Section)
- **视觉层**：全屏 HTML5 背景视频 (`<video muted loop autoplay playsinline>`)，展现岛屿风光、航拍概况；若网络欠佳则无缝置换为高清宽屏图片 (`Hero Image`)。
- **互动层**：中央以高雅衬线体显示“美丽度假酒店 (MEILI RESORT HOTEL)”及其核心 Slogan（如：“法属波利尼西亚中心的全套房私人海岛天堂” 或定制的欢迎语）。
- **预订功能**：居中或底部的快速预订组件 (Booking Bar)，浮在画面上方。

## 2. 酒店介绍 (Hotel Intro / Overview)
- **布局**：大面积留白，搭配极简文字排版。
- **内容主旨**：一段有温度的文字或创始人寄语，描述“静逸桃源”、“水上别墅与套房”的主旨，强调酒店的超优越地缘位置和宁静感。

## 3. 别墅与套房 (Villas & Suites Showcase)
- **展现形式**：大图轮播 (Carousel) 式的横向浏览，或网格卡片瀑布流。
- **元素**：
  - 类别名 (例如：“单卧室海滩景观水上别墅套房”)。
  - 悬浮于图片或位于下方的简短特性说明。
  - 行动号召 (CTA)：`[查看房价]`、`[详情]`。

## 4. 优惠精选摘要 (Selected Offers Carousel)
- 将站点的 `/offers` 区的多个核心活动进行快照展示，每个卡片对应一个活动概念（如：“尊享更多 — 消费额度”、“康体之旅”、“悠享天堂之居”、“提前预订特惠”）。
- **CTA**：提供 `[查看优惠]` 链接与 `[全部优惠]` 按钮。

## 5. 播客与专栏精华 (Highlights & Storytelling)
- **原标杆参考**：“精彩波拉波拉，四季呈献”。
- **项目落地**：将其重构为 **“精彩美丽，美丽呈献”** 播客或人文内容专栏区。
- **承载诉求**：不仅在于“住”，更在于体验。分享主厨介绍，文化讲解（如 Tamari’i 图集），以及“浪漫晚餐”定制等特色化服务板块，提升酒店故事性与亲和地气。

## 6. UGC 与社群流 (#MEILIRESORTHOTEL)
- 参考四季将住客照片 (Instagram 接入或内容精选图集) 平铺展现，建立口碑背书。
- 行动短语：“访问 @meiliresort 和 #meiliresort，探索四海宾朋在美丽度假酒店收获的难忘体验。”

## 7. 底部导航栏与超级页脚 (Footer Navigation)
极富功能性与延展服务深度的页底锚点：
- **通讯信息栏**：地理位置段落，快速拨打的本地或国际电话、电子邮件支持与在线客服链接。
- **Additional Links (附加导航链接)**：涵盖包括：返回主页、关于美丽酒店、职场资讯、隐私政策、联系我们、无障碍政策等企业级别入口。
- **设计彩蛋**：页底会引入沉浸深色调背景（如深蓝色 `#003865`）以完美收尾用户的下滑动作。
